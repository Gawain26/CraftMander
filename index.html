Up and Running in Four Steps

No installs. No account. Works entirely in your browser.

01 Generate an API Key

Visit account.arena.net/applications, create a new key with inventories and wallet permissions, and copy it.

02 Paste it in the ⚡ Panel

Click the ⚡ API tab on any page, paste your key, and save. Materials and prices load automatically.

03 Build Your Watchlist

Search for recipes on the Explorer or bulk-add a Library collection. Drag items to prioritise them for Serial Mode.

04 Craft & Profit

Check the Dashboard for craftability, Revenue for TP value, or open GW2Efficiency for step by step instructions — all in one click.

🔒
Your Data Stays With You

CraftMander stores your API key only in your browser's local storage — never on any external server. Material data is cached for the current browser tab only and discarded when you close it. No accounts. No tracking.
