What is CraftMander?

CraftMander is a Guild Wars 2 crafting tool that connects to your GW2 account and tells you which recipes you can craft right now based on your current material storage.

You build a personal watchlist of recipes you care about — either by searching manually or loading a curated Library — then check the Dashboard to see your craftability status at a glance, or head to the Revenue page to rank items by their Trading Post value.

ℹ️ Your watchlist and API key are saved locally in your browser and persist between sessions. No data is stored on any server.
🔑

Setting Up Your API Key

CraftMander needs a GW2 API key to read your material storage. Here's how to create one:

  1. Go to account.arena.net/applications and log in with your GW2 account.
  2. Click New Key and give it a name (e.g. "CraftMander").
  3. Enable the inventories and wallet permissions.
  4. Copy the generated key and paste it into the API Connection Panel (the ⚡ API tab on the right edge of every page).
  5. Click Save. Materials and Trading Post prices will be fetched automatically and the panel will update.
💡 Your key is saved in your browser's local storage after the first successful load, so you won't need to re-enter it each visit.
ℹ️ The wallet permission is needed to check craftability of recipes that require wallet currencies (such as Research Notes or Rift Essence) as ingredients. Without it, those recipes will always show as uncraftable.
⚡

API Connection Panel

All pages

The API Connection Panel is a floating panel anchored to the right edge of every page. It's the single place to manage your GW2 API key and check connection status — no matter which page you're on.

The panel appears as a small ⚡ API tab. Click it to expand; click again or press the ✕ button to collapse. The panel remembers its open or closed state as you navigate between pages. If no API key is stored when you first visit, the panel opens automatically to invite you to enter one.

Panel contents

Element Description
Key status dot + label Shows whether a key is currently stored. green = key present; dimmed = no key. Read-only — use the pencil button to change it.
✏ Pencil button Opens a text field for entering or replacing your API key. Press Enter or click Save to store the key and trigger an immediate fetch. Press Esc to dismiss without saving.
Account name Displayed after a successful fetch. Shows your GW2 account name (e.g. Username.1234). Hidden when no key has been successfully used.
State lights Four indicator lights described in detail below.
↻ Refresh Materials & Prices Manually re-fetches materials, wallet, and Trading Post prices using the stored key. Useful after crafting in-game or after adding new items to your watchlist. Spins while fetching.

State lights

Four small indicator dots show the health of your connection at a glance.

Light What it means How it's determined
Inventories permission green = materials returned data; amber = fetch succeeded but returned empty (permission likely missing) Inferred from whether the materials fetch returned a non-empty result.
Wallet permission Same logic as Inventories, applied to the wallet endpoint. Inferred from whether the wallet fetch returned a non-empty result.
Materials fetched green = data loaded, timestamp shown; amber = data loaded but items have been added to your watchlist since the last fetch, so new ingredient requirements may not be reflected. Goes amber only when new items are added to the watchlist — not when items are removed or reordered, since those changes don't require fresh material data.
Prices fetched green = TP prices loaded, timestamp shown; amber = a newly added watchlist item has no cached price yet. Goes amber only when an added item's output ID is absent from the price cache. Removing items never invalidates the cache — their prices are retained in case the item is re-added.

Stale data indicator

The Materials and Prices lights dim to amber only when items are added to your watchlist after the last fetch. Removing items or reordering them leaves both lights green — the existing cached data remains fully valid. Click ↻ Refresh Materials & Prices to bring everything up to date after adding new items.

💡 Trading Post prices are fetched alongside materials automatically on every page load — you don't need to do anything extra to get price data for the Revenue page.

Recipe Explorer

Explorer page

The Explorer is where you search for individual recipes and add them to your watchlist. Type any item name in the search box and matching recipes will appear instantly.

Element Description
Search box Filters recipes in real time as you type. Matches anywhere in the item name.
+ Watch button Adds the recipe to your watchlist. Changes to ✔ Added once it's on the list.
Item rarity color Names are colored by rarity — grey (Basic), blue (Fine), green (Masterwork), yellow (Rare), orange (Exotic), pink (Ascended), purple (Legendary).
Watchlist panel Shows all watched recipes. Click ✖ to remove an item. No craftability info is shown here — load materials via the API Connection Panel for that.

Dashboard

Dashboard page

The Dashboard is the main view for seeing what you can craft. After loading your materials via the API Connection Panel, each watchlist item shows a live craftability badge.

Badge Meaning
✓ Ready You have all the required ingredients in your material storage right now.
✗ Missing One or more ingredients are missing or insufficient.
(no badge) Materials haven't been loaded yet — use the ⚡ API panel to enter your key and fetch materials.
💡 Craftability checks are recursive — if an ingredient can itself be crafted from your materials, CraftMander accounts for that automatically.

Clicking a watchlist item

Clicking any item in the watchlist opens the Recipe Detail panel at the bottom of the page. This shows the full crafting tree with per-ingredient have/need counts, plus quick links to the GW2 Wiki and GW2Efficiency.

💰

Revenue

Revenue page

The Revenue page ranks your craftable watchlist items by their Trading Post value, so you can see at a glance which crafts are worth the most right now. Prices are fetched live from the GW2 API alongside your materials — no extra steps required.

Column Description
Item The output item name, colored by rarity.
GW2E A ⚙ link that opens the item directly in the GW2Efficiency crafting calculator in a new tab.
Qty Craftable How many times you can craft this item from your current materials, calculated independently per item.
Instant Sell (net) Revenue if you sell immediately to the highest active buy order. Net of the 15% TP fee (5% listing + 10% sales tax). Multiplied by quantity craftable.
List & Wait (net) Revenue if you post at the current lowest sell listing price. Same fee deduction and quantity multiplication. Typically higher than Instant Sell but requires waiting for a buyer.

Sorting and refreshing

The table defaults to sorting by List & Wait revenue descending — highest potential value first. Click any column header to sort by that column; click again to reverse the order.

Prices are cached for the current browser session and reused as you navigate between pages. Click ↻ Fetch Prices & Recalculate to force a fresh fetch from the GW2 API, or use ↻ Refresh Materials & Prices in the ⚡ API panel to refresh everything at once.

Items showing —

A dash in a price column means the item has no active Trading Post listing of that type — either no buy orders exist (for Instant Sell) or no sell listings exist (for List & Wait). This is common for rarely traded items. The item is still shown so you can see its craftable quantity.

💡 Revenue figures reflect total proceeds across all craftable copies, not per-craft. An item you can craft 10 times at 50s each will show 5g, not 50s.
ℹ️ Revenue calculations don't account for the cost of ingredients — only sale proceeds are shown. Use GW2Efficiency (via the ⚙ link) for a full profit breakdown including material costs.

Libraries

Libraries page

Libraries are curated collections of related recipes — for example, all recipes required for a specific Faction Provisioner vendor. Instead of searching one by one, you can add or remove an entire collection at once.

  1. Select a collection from the left sidebar.
  2. The middle panel previews all recipes in the collection, with craftability badges if your materials are loaded, and a Watching tag for items already on your watchlist.
  3. Click ＋ Add All to Watchlist to add every recipe in the collection, or ✖ Remove All from Watchlist to remove them all at once.
ℹ️ Collections labeled — TODO are placeholders for future recipe sets that haven't been fully confirmed yet. They won't appear in the sidebar until their recipes are filled in.
📋

Watchlist

Your watchlist persists across all pages and is saved automatically to your browser's local storage. Items remain on the list until you remove them manually.

Action How
Add a recipe Search for it on the Explorer, or use Add All on the Libraries page.
Remove one recipe Click the ✖ button on any watchlist item.
Reorder Drag any item by its ⠿ handle on the left to move it up or down. Order affects Serial Mode — items higher in the list get first pick of shared ingredients.
Clear entire watchlist Click the 🗑 button in any watchlist panel header. You'll be asked to confirm before anything is deleted.

Serial Mode

Dashboard page

The default craftability check treats each recipe independently — as if your full material stack is available for each item. Serial Mode simulates crafting recipes in order, consuming ingredients as you go.

This answers the question: "If I craft these items one after another, how many can I actually complete before I run out of materials?"

Reading the serial mode indicators

Indicator Meaning
✓ (green) This item is craftable in sequence — materials are still available when its turn comes.
✗ (red, dimmed) Materials were used up by earlier crafts — this item can't be made.
– (grey, faded) Manually excluded from the serial run. Click to re-include.

Craft All in GW2Efficiency

When Serial Mode is active and at least one item is craftable in series, the ⚙ Craft All in GW2Efficiency button appears. It opens the GW2Efficiency crafting calculator pre-loaded with all the items that made the cut, so you can get a full shopping list instantly.

💡 Order matters in Serial Mode — the watchlist is processed top-to-bottom. Items at the top get first pick of shared ingredients. Drag items by their ⠿ handle to fine-tune priority without removing anything.
🌿

Crafting Tree

Dashboard page

Clicking a watchlist item on the Dashboard expands the Recipe Detail panel, which includes a full crafting tree showing every ingredient and how many you currently have.

Element Description
▶ toggle button Expand an ingredient's own sub-recipe (if one exists). Click again to collapse. Nests up to 4 levels deep.
have/need count Shows how many of this ingredient you have vs. how many are needed. Green = sufficient, red = insufficient.
Currency ingredients Some recipes require wallet currencies (e.g. Research Notes, Rift Essence) instead of crafted items. These are shown by name with your current wallet balance — they have no sub-recipe toggle since currencies can't be crafted.

External Links

CraftMander links out to two external tools in several places:

Link Where it appears What it does
📖 GW2 Wiki Dashboard recipe detail panel Opens the official Guild Wars 2 wiki page for the output item.
⚙ GW2Efficiency (single item) Dashboard detail panel; Revenue table (GW2E column) Opens the GW2Efficiency crafting calculator pre-loaded with this single item — full materials breakdown, sourcing, and profit calculation.
⚙ Craft All in GW2Efficiency Dashboard serial mode summary bar Opens GW2Efficiency pre-loaded with every item that passed the serial mode check, giving a combined shopping list for the whole batch.
